# 🧠 Machine Learning & Data Science Daily Lab

Welcome to the **Machine Learning & Data Science Daily Lab**! This repository is an open-source, daily-updated educational resource featuring clean, documented Python implementations, algorithm breakdowns, math explanations, and practical notes designed to help developers, students, and practitioners master machine learning and data science from first principles.

---

## 📚 Curriculum Structure

| Module | Topic | Core Contents |
| :--- | :--- | :--- |
| **01-python-data-science** | NumPy & Vectorization | Array operations, broadcasting, linear algebra, vectorization benchmarks |
| **02-pandas-data-wrangling** | Data Manipulation & Cleaning | Missing value imputation, groupby aggregations, merges, feature prep |
| **03-exploratory-data-analysis** | EDA & Feature Engineering | Distributions, correlation matrices, outlier detection, scaling |
| **04-supervised-learning** | Regression & Classification | Linear & Logistic Regression from scratch, Gradient Descent, Regularization |
| **05-ensemble-algorithms** | Trees & Boosting | Decision Trees, Random Forests, AdaBoost, Gradient Boosting |
| **06-unsupervised-learning** | Clustering & PCA | K-Means, Silhouette analysis, PCA dimensionality reduction |
| **07-deep-learning-foundations** | Neural Networks | Perceptrons, activation functions, backpropagation intuition, PyTorch basics |
| **08-notes-and-cheatsheets** | Interview Prep & Concepts | Bias-Variance tradeoff, Precision-Recall, ROC-AUC, ML system design notes |

---

## 🎯 Daily Study Cadence
Each day features **7 to 8 focused, bite-sized commits**:
- High-quality runnable Python code (`.py`) with clean docstrings.
- Educational Markdown notes (`.md`) with formulas, diagrams, and explanations.
- Designed to build a comprehensive, public knowledge base while maintaining a healthy coding habit.

---

## 🚀 How to Run Locally
Clone the repository and run any practice module:
```bash
git clone https://github.com/mzb000/daily-tracker.git
cd daily-tracker
python <module-folder>/<script-name>.py
```
